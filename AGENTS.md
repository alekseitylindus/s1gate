## Agent skills

### Issue tracker

Issues and specs for this repo live as GitHub issues, read and written with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage roles map to the five default label strings, unchanged: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
